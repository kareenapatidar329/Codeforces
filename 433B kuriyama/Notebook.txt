🔹 Pattern

Prefix Sum + Sorting + Range Query

1) Problem Story (Simple Explanation)

Ek ladki ke paas n stones hain.

Har stone ki ek value hai.

Example:

a = [6,4,2,7,2]

Usse m queries answer karni hain.

Har query me:

type l r

diya hoga.

Do types hain:

Type 1:
1 l r

Original array me index l se r tak ka sum batao.

Example:

Original:
[6,4,2,7,2]

Query:
1 2 4

Answer:
4+2+7 = 13
Type 2:
2 l r

Pehle array ko sort karo.

[6,4,2,7,2]

Sorted:
[2,2,4,6,7]

Phir sorted array me l se r tak ka sum batao.

Example:

2 2 4

2+4+6 = 12
2) Brute Force Approach

Har query ke liye:

Agar type 1 hai:

original array me l se r tak loop chalao
sum calculate karo

Agar type 2 hai:

sorted array me l se r tak loop chalao
sum calculate karo
Brute Code Idea:
for every query:

    if type == 1:

        sum = 0

        for i = l to r:
            sum += original[i]


    else:

        sum = 0

        for i = l to r:
            sum += sorted[i]


    print sum

Example:

Original:

                6  10  12  19  21

7) Range Sum Formula

Agar:

l to r

ka sum chahiye:

Formula:

prefix[r] - prefix[l-1]

Reason:

Example:

Need:

index 3 to 5

Prefix:

prefix[5]

=
1+2+3+4+5

Extra part:

1+2

Remove:

prefix[2]

Remaining:

3+4+5
8) Optimized Approach
Step 1:

Input array lo.

Step 2:

Original prefix banao.

prefixOriginal[i]
=
prefixOriginal[i-1]+a[i]
Step 3:

Array ka copy banao.

Sort karo.

Step 4:

Sorted prefix banao.

Step 5:

Queries answer karo.

If:

type == 1

Use:

prefixOriginal

Else:

prefixSorted
9) Optimized Pseudocode
Input n

Create original array

Create prefixOriginal


for i = 1 to n:

    input a[i]


for i = 1 to n:

    prefixOriginal[i] =
    prefixOriginal[i-1]+a[i]



Create sorted array copy

Sort sorted array


for i = 1 to n:

    prefixSorted[i] =
    prefixSorted[i-1]+sorted[i]



Input m


for every query:

    input type,l,r


    if type == 1:

        answer =
        prefixOriginal[r]-prefixOriginal[l-1]


    else:

        answer =
        prefixSorted[r]-prefixSorted[l-1]


    print answer

14) Interview Explanation ⭐

Question: Explain your approach.

Answer:

"Since the problem contains multiple range sum queries, calculating the sum every time would be inefficient. I used prefix sums to preprocess the array. I created one prefix array for the original order and another prefix array for the sorted order. For each query, based on the type, I select the appropriate prefix array and answer the range sum in O(1) using prefix[r] - prefix[l-1]. Sorting takes O(n log n), so the overall complexity is O(n log n + m)."
