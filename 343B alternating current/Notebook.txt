Code
import java.util.*;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        String s = sc.next();

        Stack<Character> stack = new Stack<>();

        for(int i = 0; i < s.length(); i++){

            char curr = s.charAt(i);

            if(!stack.isEmpty() && curr == stack.peek()){

                stack.pop();

            }else{

                stack.push(curr);

            }

        }

        if(stack.isEmpty()){

            System.out.println("YES");

        }else{

            System.out.println("NO");

        }

        sc.close();

    }

}

Interview Explanation

I use a stack to simulate adjacent character cancellation. While traversing the string, if the current character matches the stack top, I remove the top because both characters cancel each other. Otherwise, I push the current character into the stack. After processing the entire string, if the stack is empty, all characters were cancelled successfully, so the answer is YES; otherwise, it is NO.

Pattern Sheet ⭐

Pattern Name: Stack Cancellation

Recognition Clues:

Adjacent elements disappear/remove.
Cancellation may create new adjacent pairs.
Only the latest unmatched element matters.
